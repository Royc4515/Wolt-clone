# Videos

Screen recordings for the headline flows (IDs `V1`–`V5` in the [Media Capture Guide](../../00-Media-Capture-Guide.md)).

Two ways to include a video on GitHub:

1. **Embed from the PR (recommended, no repo bloat):** drag the `.mp4` into the pull-request description; GitHub returns a `user-attachments` URL you paste on the page (this is how the main [README](../../../README.md#-demo-videos) embeds its clips).
2. **Commit the file here:** drop a compressed `.mp4` in this folder and link it from the page (e.g. `[flow-order.mp4](assets/video/flow-order.mp4)`). Keep files small.

Screenshots are the primary deliverable; videos are a bonus layer.
